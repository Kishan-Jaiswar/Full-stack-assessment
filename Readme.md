# 📝 Task Manager (Full Stack)

A simple full-stack task manager built using **React, Node.js, Express, and MongoDB**.
It allows users to create, update, filter, and delete tasks.

---

## 🚀 Features

* Add task (title + description)
* View all tasks
* Update status (Pending / WIP / Done)
* Delete task
* Filter tasks by status
* Responsive UI

---

## 🛠️ Tech Stack

* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express
* **Database:** MongoDB

---

## ⚙️ Run Locally

### Backend

```bash
cd Backend
npm install
npm run dev
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

---

## 🔌 API

* `POST /tasks` → Create task
* `GET /tasks` → Get all tasks
* `PATCH /tasks/:id` → Update status
* `DELETE /tasks/:id` → Delete task
